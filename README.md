# Chaotic Gaming Website

Community site for Chaotic Gaming - a Chaotic Minds Collective division.

## Stack
- Next.js 14 (App Router) + Tailwind CSS
- Deploys on Vercel (Hobby plan, free)
- Domain: chaoticmindsgaming.com (Hostinger DNS -> Vercel)

## Develop
```
npm install
npm run dev
```

## Brand
- Black #0D0D0F / charcoal #1A1A1D / smoke #36393F
- Purple #A020F0 (brand), violet #9B59B6, cyan #00E5FF (interactive accents)
- Purple-to-cyan gradients for CTAs
- Philosophy: Community built by gamers, for gamers.
